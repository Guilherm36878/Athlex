# Princípios de Navegação ATHLEX

Toda funcionalidade deve obedecer aos seguintes princípios:

1. O usuário nunca deve precisar de mais de 3 cliques para chegar a uma função principal.

2. O menu principal deve possuir no máximo 6 opções.

3. Cada tela deve possuir apenas um objetivo principal.

4. O usuário deve sempre saber em qual módulo está.

5. O botão "Início" deve estar disponível em todas as áreas.

6. Configurações e Logout permanecem sempre no menu do perfil.

7. Um perfil nunca visualizará funcionalidades que não pode utilizar.

8. O Dashboard sempre será o ponto central da navegação.

Até aqui, sua ideia está correta e é intuitiva.

## Depois do login

Depois de entrar, o usuário não deve cair diretamente em uma página muito específica.

Ele deve chegar a um **painel principal**, que funciona como hub.

```text
LOGIN
  ↓
PAINEL PRINCIPAL
  ├── Resumo do dia
  ├── Atalhos principais
  ├── Alertas
  ├── Próximos compromissos
  └── Menu de navegação
```

Esse painel muda de acordo com o perfil.

# Como evitar que o usuário se perca

## 1. Sempre ter um botão “Início”

O usuário deve conseguir voltar ao painel principal em qualquer tela.

## 2. Mostrar onde ele está

Exemplo:

```text
Planejamento > Microciclo > Semana 03
```

Isso é chamado de breadcrumb.

## 3. Não mostrar funcionalidades que o perfil não usa

O atleta não precisa enxergar:

* gestão de usuários;
* planejamento anual;
* relatórios institucionais.

O gestor não precisa ter acesso direto ao formulário de PSE de um atleta.

## 4. Usar atalhos no dashboard

O painel inicial deve mostrar apenas as ações mais comuns.

Exemplo do atleta:

```text
Responder bem-estar
Ver treino
Confirmar presença
Ver próximo jogo
```

## 5. Agrupar configurações e logout

Não coloque “Sair” perdido no menu principal.

O ideal:

```text
Foto do usuário
Nome
Perfil atual
────────────
Meu perfil
Configurações
Trocar função
Sair
```

## 6. Suportar perfis acumuláveis

Um usuário pode ser gestor e técnico. Nesse caso, ele não deve misturar as funções na mesma tela. Deve existir uma opção:

```text
Você está usando:
[ Técnico ▼ ]

Alternar para:
Gestor
```

Isso está alinhado à regra de perfis acumuláveis definida no documento.

# Mapa de navegação para a Sprint 1

Para a Sprint 1, não precisamos desenhar todas as páginas internas. Basta definir o esqueleto:

```text
index.html
│
├── explorar.html
│
└── paginas/autenticacao/login.html
    │
    ├── paginas/cadastros/cadastro-atleta.html
    ├── paginas/cadastros/cadastro-treinador.html
    └── paginas/cadastros/cadastro-dirigente.html
         │
         └── paginas/boas-vindas/
             ├── boas-vindas-atleta.html
             ├── boas-vindas-treinador.html
             └── boas-vindas-gestor.html
                  │
                  └── paginas/modelos/dashboard-base.html
```
